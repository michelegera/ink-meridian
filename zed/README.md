# Ink Meridian · zed

Editor colour theme for [Zed](https://zed.dev), built on the Ink Meridian palette.
Ships with both dark and light variants.

## Install

```bash
mkdir -p ~/.config/zed/themes
cp zed/ink-meridian.json ~/.config/zed/themes/
```

## Verify

Open the Theme Selector inside Zed (`Cmd+K Cmd+T` / `Ctrl+K Ctrl+T`) and
select **Ink Meridian Dark** or **Ink Meridian Light**.
